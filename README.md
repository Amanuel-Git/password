# Password Generator and Rater

A simple static website for generating secure passwords and evaluating the strength of existing passwords.

## Overview

This project provides a small informative web app with:

- A homepage explaining password security and usage.
- A password generator page.
- A password rater page.
- A contact page.

## Features

- Responsive navigation menu.
- Password generator UI.
- Password strength evaluation UI.
- Simple, static HTML/CSS/JavaScript implementation.

## Project Structure

- `index.html` - Homepage.
- `pages/generator.html` - Password generator page.
- `pages/rater.html` - Password strength rater page.
- `pages/contact.html` - Contact information page.
- `styles/` - CSS styles for the site.
- `scripts/` - JavaScript for navigation and page behavior.
- `fonts/` - Font assets used by the site.

## How to Use

1. Open `index.html` in your web browser.
2. Use the navigation links or buttons to access the generator and rater pages.

## Notes

- This is a static project and does not require a web server.
- Make sure the folder structure remains intact so linked pages, styles, and scripts work correctly.
