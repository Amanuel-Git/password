Password Generator and Rater

Introduction to password security

Password is a memorized string of characters used to authenticate user's identity before granting them access to a service. To be effective, passwords should be hard to guess and long. By using short or easy to guess passwords we make ourselves venerable attacks like brute force and dictionary attack.

Purpose of this project

One of the main purposes of this project is to provide an easy way to generate hard to crack passwords that can be copy pasted from the website. Another purpose is evaluating the strength of already created passwords. You can use the below button to generate or rate passwords.
